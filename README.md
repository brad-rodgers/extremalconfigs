# Hilbert inequality and reformulation
For fixed $N \geq 2$ and fixed $\lambda_1 < \cdots < \lambda_N$, let $C_N(\lambda_1,...,\lambda_N)$ be the optimal constant $C$ in the inequality

$$\Big| \sum_{\substack{1 \leq m,n \leq N \\ m \neq n}}  \frac{w_m \overline{w_n}}{\lambda_m - \lambda_n} \Big| \leq C \sum_{1\leq m \leq N} \frac{|w_m|^2}{\delta_m},$$

where $\delta_n = \min_{m\neq n}|\lambda_m-\lambda_n|$ and $w_1,...,w_N$ are arbitrary real or complex numbers. This may be phrased in terms of the spectral radius of the $N\times N$ skew-symmetric matrix $B_N(\lambda_1,...,\lambda_N)$ with entries $b_{jk}$ given by

$$b_{jk} = \begin{cases} 
\sqrt{\delta_j \delta_k}/(\lambda_j - \lambda_k) & \textrm{for}\; j\neq k \\
0 & \textrm{for}\; j = k.
\end{cases}$$

Let

$$C_N = \sup_\lambda \rho(B_N(\lambda_1,...,\lambda_N)),$$

 let $C_N(\lambda_1,...,\lambda_N)$ be the optimal constant $C$ in \eqref{eq:infinite_Hilbert} (valid for all $w \in \mathbb{C}^N$). This may be phrased in terms of the spectral radius of the $N\times N$ skew-symmetric matrix $B_N(\lambda_1,...,\lambda_N)$ with entries $b_{jk}$ given by
\[
b_{jk} = \begin{cases} 
\sqrt{\delta_j \delta_k}/(\lambda_j - \lambda_k) & \textrm{for}\; j\neq k \\
0 & \textrm{for}\; j = k.
\end{cases}
\]
Then it is easy to see 
\begin{equation}
\label{eq:C_N_specrad}
C_N = \sup_\lambda \rho(B_N(\lambda_1,...,\lambda_N)),
\end{equation}
where $\rho$ is the spectral radius. Furthermore $C = \lim_{N\rightarrow\infty} C_N$ will be the optimal absolute constant such that \eqref{eq:infinite_Hilbert} holds for all $N$, $\lambda$, $w$.

It is therefore of some interest to understand extremal configurations of $\lambda$ which realize the supremum in \eqref{eq:C_N_specrad}.\footnote{It is an easy exercise in analysis using translation and dilation invariance in $\lambda$ of $B_N$ to see that the supremum is actually realized for each $N$.} Because $B_N(\lambda_1,...,\lambda_N)$ is translation and dilation invariant in $\lambda$, we lose no generality in fixing the conventions that $\lambda_0 = 0$ and that the smallest gap between any of the $\lambda_j$ is $1$. We can thus describe a configuration $\lambda_1,...,\lambda_N$ by listing the $N-1$ gaps which we label $g_1,...,g_{N-1}$. It will be convenient in discussing gap lists to introduce the notation that if a gap size $g$ is repeated $r$ times, we write this as $g^{[r]}$. So for instance the configuration $\lambda_1 < \cdots < \lambda_5$ given by $0 < 1 < 4 < 7 < 7.5$ would be described by the gap list $1, 3^{[2]}, 0.5$.

The gap lists for those configurations which realize the supremum in \eqref{eq:C_N_specrad} appear to follow a curious pattern. For $2 \leq N \leq 20$ it appears numerically that extremal configurations are those with the gap list,
\[
1^{[N-1]}.
\]
But for $N = 21$ this pattern of equal spacings breaks down. Numerically the extremal gap list appears to be approximately
\[
a, 1^{[18]}, a \quad \textrm{where}\; a = 3.47
\]
To take another example, for $N = 46$ the extremal gap list appears to be approximately
\[
a, b^{[2]}, 1^{[39]}, b^{[2]}, a \quad \textrm{where}\; a = 19.15, \, b = 5.71
\]

A collection of candidate extremal gap lists for $2 \leq N \leq 48$ can be found at [github link] along with the programs used to find the gap patterns (generated by ChatGPT 5.6 Sol). These candidates for extremal gap lists were found via a multistart optimization routine in a high dimensional nonconvex domain; so while it is reasonable to believe they are close approximations to the actually extremal configurations, no proof of this exists for general $N$.

From numerical data one may somewhat tenuously make the following conjectures about gap lists $g_1,...,g_{N-1}$ for extremal configurations in dimension $N$:

\begin{enumerate}
\item The gap list is symmetric; that is $g_{N-j} = g_j$ for all $N$ and $j$.

\item For each $N$ the gap list can be written
\[
\gamma_L^{[n_L]}, \gamma_{L-1}^{[n_{L-1}]},...,\gamma_1^{[n_1]}, \gamma_0^{[n_0]}, \gamma_1^{[n_1]},..., \gamma_L^{[n_L]},
\]
for some $L = L_N$ and values $\gamma_0,...,\gamma_L$ and $n_0,...,n_L$ also depending on $N$ with the normalization $\gamma_0 = 0$, and with the further properties that $\gamma_{j+1} > \gamma_j$ while $n_{j+1} \leq n_j$ for all $j$.

\item $L_N = (\log N)/(\log \pi) + O(1)$.

\item $n_0 \sim \left(1-\frac{1}{\pi}\right)N$ as $N\rightarrow\infty$.

\item $n_j \sim \frac{1}{2}\left(1-\frac{1}{\pi}\right) \frac{1}{\pi^j} N$ as $N\rightarrow\infty$ for all fixed $j\geq 1$.
\end{enumerate}

For each fixed $j$ it seems $\gamma_j$ grows polynomially fast with $N$, at a rate which increases the larger $j$ is. It may even be that $\gamma_j = N^{j+o(1)}$.
